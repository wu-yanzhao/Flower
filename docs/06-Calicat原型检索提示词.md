# 06 · Calicat 原型检索提示词速查表

> 配套《鲜花订购与管理系统》，用于在设计阶段快速找到可复用的**整页原型模板 / 组件 / 图标 / 图表 / 图片素材**。
> 所有提示词均按本系统**已实现的页面与功能**对齐，可判断匹配度后直接复用或微调。

---

## 零、使用前先读这一段

### Calicat 里提示词有三种用法，别混用

| 用法 | 入口 | 本表标记 | 说明 |
| --- | --- | --- | --- |
| AI 生成整页原型 | 「AI 设计助理」输入框 | **【AI生成】** | 粘贴长句自然语言，直接产出高保真页面，最适合整页 |
| 资源库检索 | 组件库 `Shift+I` / 图片库 / 图标库搜索框 | **【模板】【组件】【图标】【图表】【图片】** | 粘贴短关键词，命中现成素材，最快 |
| 模板中心检索 | 模板搜索 | **【模板】** | 搜整页/整套模板，命中后替换文案即可 |

### 本系统的视觉基线（生成时务必带上，否则配色会跑偏）

| 项目 | 取值 |
| --- | --- |
| 主色（玫红/桃花粉） | `#e4577a`，深态 `#cf3f63`，浅底 `#fff1f4` |
| 辅助色（草绿） | `#6fae7c`，浅底 `#eef8f0` |
| 点缀色（金） | `#d9a441` |
| 后台侧边栏 | 深梅色渐变 `#4a343a → #3a2b30` |
| 整体风格关键词 | 清新花艺 · 粉色系 · 大图卡片 · 圆角 · 留白充足 · 简约电商 |

**推荐做法**：把下面这段「风格锚点」拼在任何一条 AI 生成提示词末尾，命中率明显更高：

```
配色以玫红 #e4577a 为主色、草绿 #6fae7c 为辅色、米白 #faf7f5 为背景，
圆角 12px 卡片，大图优先，留白充足，清新花艺风格，不要深色背景。
```

### 一条省时间的捷径（强烈建议先试）

Calicat 有**网页提取设计**的 Chrome 插件，可以一键把网页转成可编辑原型。
你的系统已经能跑起来，所以最高效的路径是：

1. 双击 `启动项目.bat`，访问 `http://localhost:3000/`
2. 用插件提取首页 / 商品列表 / 商品详情 / 后台概览
3. 在提取结果上改文案和配色

**这比从零检索模板快得多，而且和你现有系统 100% 一致。**
下面的检索词用于「提取结果不满意、想换排版参考」或「补充局部组件」时。

## 十一、使用技巧与避坑

1. **先用网页提取，再检索**：你的系统已经能跑，用 Calicat 的 Chrome 插件提取页面是最省事的路径，检索词只作为排版参考的补充。
2. **AI 生成务必带色值**：不带配色描述时默认常出蓝色系科技风，与本系统玫红花艺调性冲突，请拼接「零、」章节的「风格锚点」。
3. **一次只生成一页**：把整站塞进一条 prompt 会让版式变糊，按上面 8 个模块分条生成再拼装成一套。
4. **先模板后组件**：搜到整页模板后用「智能填充/样式替换」换色换文案，比从组件逐个搭快 3–5 倍。
5. **后台涨红跌绿**：本系统按国内习惯，销售额上升用红色、下降用绿色；若搜到的模板相反，记得手动改，答辩时这是一个加分细节。
6. **生成后回灌**：在 Calicat 定稿的界面可直接作为论文「系统实现」章节的界面截图，配合 `docs/01-需求分析与系统设计.md` 的模块划分一起贴图。

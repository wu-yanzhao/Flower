# 前后端分工运行说明

> 目标：**前端用 Node 独立启动，后端放进 IDEA 管理调试**，改页面不用重启后端，答辩演示也更稳。
>
> 适用版本：Node.js ≥ 18（推荐 22.5+，本机为 v24.14.1，可直接用内置 `node:sqlite`）

---

## 一、整体分工

| | 后端服务 | 前端静态服务 |
| --- | --- | --- |
| 目录 | `E:\Flower\server` | `E:\Flower\web` |
| 入口 | `src/app.js` | `server.js` |
| 默认端口 | `3000` | `5173` |
| 启动方式 | IDEA 运行配置 `1 后端服务 3000` | `npm start` 或双击 `启动前端.bat` |
| 依赖 | `express`（唯一第三方包） | **无**，纯 Node 内置模块 |
| 职责 | REST 接口 `/api/*`、鉴权、SQLite 读写 | 页面/样式/脚本/图片静态托管，并把 `/api/*` 转发给后端 |
| 编辑器 | IntelliJ IDEA | 任意（VS Code / WebStorm 均可） |

两个进程通过 HTTP 通信，关系的实质是：

```
浏览器 ──> 前端服务:5173 ──静态资源──> web/ 目录
                │
                └──/api/* 转发──> 后端服务:3000 ──> SQLite
```

## 二、后端：在 IDEA 里跑

### 2.1 用哪个项目目录打开

**用 IDEA 打开 `E:\Flower\server`**（不要打开整个 `E:\Flower`，否则 Maven/Gradle 模块识别会更混乱）。
该目录下已有 `.idea` 配置，并已内置好运行配置。

### 2.2 检查节点解释器（只做一次）

IDEA 需要知道 Node 在哪。路径：
`File → Settings → Languages & Frameworks → Node.js`

- **Node interpreter**：填 `E:\Node\node.exe`
- **Package manager**：`npm`（`E:\Node\npm`）

> ⚠️ 这一步很关键。项目用到了 Node 内置的 `node:sqlite`，
> **要求 Node ≥ 22.5**。若解释器是旧版本（如 16/18），启动会报
> `Cannot find module 'node:sqlite'`，此时需在 `server` 目录执行 `npm install better-sqlite3` 兜底。

### 2.3 已内置的 5 个运行配置

位置：`E:\Flower\server\.idea\runConfigurations\`，IDEA 打开项目后会自动出现，
在右上角运行配置下拉框里选择即可。

| 运行配置名 | 对应文件 | 用途 |
| --- | --- | --- |
| `1 后端服务 3000` | `src/app.js` | 启动后端（日常最常用） |
| `2 重置演示数据` | `scripts/reset.js` | 恢复初始演示数据 |
| `3 顾客端接口测试 35项` | `scripts/smoke-test.js` | 顾客端业务链路自检 |
| `4 管理端接口测试 49项` | `scripts/admin-test.js` | 管理端写操作自检 |
| `5 前端静态服务 5173` | `../web/server.js` | 不想开终端时，也能从 IDEA 起前端 |

> 测试类配置（3、4）**必须先让后端处于运行状态**，它们是向 `localhost:3000` 发请求的。
> 如果 IDEA 没有自动识别这些配置，`File → Invalidate Caches / Restart` 一次即可；
> 仍不行就手动 `Run → Edit Configurations → + → Node.js` 照表填参数。

### 2.4 断点调试

直接用 **Debug** 按钮（虫子图标）运行 `1 后端服务 3000`，
然后在 `src/controllers/*.js` 或 `src/routes/*.js` 里打断点即可单步跟踪。
答辩时被问"某个接口怎么实现的"，现场 Debug 演示比翻代码更有说服力。

### 2.5 首次运行前要做的两件事

在 IDEA 的终端（Alt+F12）里执行：

```bash
npm install     # 安装 express
npm run reset   # 建库并写入演示数据（确认 data/flower.db 尚不存在时）
```

## 三、前端：用 Node 独立启动

### 3.1 三种启动方式（任选一种）

```bash
# 方式 A：命令行
cd E:\Flower\web
npm start            # = node server.js
npm run open         # 启动后自动开浏览器

# 方式 B：双击根目录的 启动前端.bat

# 方式 C：换个端口 / 换个后端地址（注意终端类型，语法不同！）
cd E:\Flower\web

# CMD 终端：
set PORT=8080 && node server.js
set API_TARGET=http://localhost:4000 && node server.js

# PowerShell 终端（VS Code 默认终端）：
$env:PORT="8080"; node server.js
$env:API_TARGET="http://localhost:4000"; node server.js
```

启动成功后：

| 入口 | 地址 |
| --- | --- |
| 顾客端首页 | http://localhost:5173/ |
| 管理后台 | http://localhost:5173/admin/index.html |
| 前端自检 | http://localhost:5173/health |

### 3.2 `web/server.js` 是干什么的

这是为本项目写的**零依赖静态服务器**，只做两件事：

1. 把 `web` 目录当作站点根目录对外提供 HTML/CSS/JS/SVG；
2. 把 `/api` 开头的请求**原样转发**给后端（`http://localhost:3000`）。

因此前端代码里的这一行完全不用改：

```js
var BASE = location.protocol === 'file:' ? 'http://localhost:3000/api' : '/api';
```

好处：

- **不存在跨域问题**——浏览器只看到 5173 这一个域；
- 后端可以在 IDEA 里随意重启、Debug，前端服务不受影响；
- 后端没起来时，页面会收到清晰的 `502` JSON 提示，而不是莫名其妙的空白。

> 实现细节：转发时会剔除 `host`、`transfer-encoding`、`content-length` 再由本服务重算，
> 避免 chunked 与 content-length 冲突导致后端返回 400。

### 3.3 前端用什么编辑器都行

`web` 目录是纯静态资源，任何编辑器打开即可改，改完刷新浏览器生效：

```bash
code E:\Flower\web        # VS Code
webstorm E:\Flower\web    # WebStorm
```

**不建议**用 VS Code 的 Live Server 插件预览：它的 `5500` 端口下 `/api` 不会转发，
接口会全部 404。要用它就必须额外配代理，不如直接用本项目自带的 `server.js`。

## 五、常见问题

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 前端起了但页面数据全空 | 后端没启动 | 先在 IDEA 运行 `1 后端服务 3000` |
| 前端 `EADDRINUSE: 5173` | 端口被占 | CMD：`set PORT=8080 && node server.js`；PowerShell：`$env:PORT="8080"; node server.js` |
| 后端 `EADDRINUSE: 3000` | 上一次的进程没关 | 关掉旧终端窗口，或在 IDEA 里 Stop |
| 接口返回 `502 无法连接后端服务` | `API_TARGET` 指错端口 | 核对后端真实端口后重启前端服务 |
| 报错 `Cannot find module 'node:sqlite'` | Node 低于 22.5 | 换 Node 22.5+，或 `npm i better-sqlite3` |
| 双击 bat 后乱码、报"找不到模块" | bat 被以 UTF-8 保存，cmd 按 GBK 解析错位 | **不要用编辑器把 `.bat` 另存为 UTF-8**；保持 ANSI/GBK 编码（用 VS Code 右下角编码栏改回） |
| IDEA 里中文乱码 | 文件编码不统一 | `Settings → Editor → File Encodings` 全部设为 UTF-8 |
| 改了页面没变化 | 浏览器缓存 | Ctrl+F5 强制刷新（`server.js` 已发 `no-cache`） |

## 六、答辩现场建议流程

1. 打开 IDEA，Debug 运行 `1 后端服务 3000`；
2. 双击 `启动前端.bat` 起前端；
3. 浏览器访问 `http://localhost:5173/`，按操作习惯演示顾客端；
4. 切到 `http://localhost:5173/admin/index.html` 演示后台数据看板；
5. 被追问实现细节时，直接在 IDEA 里用断点演示对应的控制器代码。

> 兜底方案：如果现场 IDEA 出问题，**双击根目录 `启动项目.bat`**，
> 一个命令起全套（后端自带静态托管），访问 `http://localhost:3000/` 即可，
> 只是这时前端改代码需要重启服务。

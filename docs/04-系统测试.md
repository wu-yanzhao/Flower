## 4.4 安全性与边界测试

| 用例 | 场景 | 结果 |
| --- | --- | --- |
| S-01 | 直接调用 `/api/cart` 不带 token | 401，前端清除失效凭证 |
| S-02 | 顾客 token 访问 `/api/admin/users` | 403 无权限 |
| S-03 | 越权查看他人订单 | 403 无权查看 |
| S-04 | 数据库中密码字段 | scrypt 加盐摘要，非明文 |
| S-05 | 订单重复支付 / 已完成后取消 | 被状态机拦截 |
| S-06 | 下单数量超过库存 | 事务回滚，库存不变 |
| S-07 | 关键词含特殊字符 | 走参数化查询，无 SQL 注入 |

## 4.5 测试执行健壮性

`npm run reset` 具备两种执行模式，避免服务占用文件导致重置失败：

| 场景 | 行为 |
| --- | --- |
| 服务未运行 | 删除 `data/flower.db` 后重建并写入演示数据 |
| 服务运行中（Windows 报 EBUSY） | 自动降级为「清空全部数据表」方式重建，数据立即生效，无需重启服务 |

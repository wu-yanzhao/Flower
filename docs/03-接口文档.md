# 03 · 接口文档

- 基础地址：`http://localhost:3000/api`
- 请求方式：RESTful，除文件上传外均使用 `application/json`
- 鉴权方式：需要登录的接口在请求头携带 `Authorization: Bearer <token>`（登录/注册接口返回 token）
- 响应格式（统一）：

```json
{
  "code": 0,              // 0 成功；非 0 为业务错误码（400 参数错误 / 401 未登录 / 403 无权限 / 404 不存在）
  "message": "操作成功",   // 可直接展示给用户的提示
  "data": { }             // 数据体；分页接口为 { list, total, page, pageSize, totalPages }
}
```

---

## 3.1 认证与用户

| 方法 | 路径 | 鉴权 | 说明 |
| --- | --- | --- | --- |
| POST | `/auth/register` | 否 | 注册，参数：`username,password,nickname,phone?,email?` |
| POST | `/auth/login` | 否 | 登录，返回 `{token, user}` |
| GET | `/auth/profile` | 是 | 当前用户信息（含购物车数、收藏数、订单数） |
| PUT | `/auth/profile` | 是 | 修改昵称 / 手机号 / 邮箱 |
| PUT | `/auth/password` | 是 | 修改密码，参数：`oldPassword,newPassword` |
| POST | `/auth/logout` | 是 | 退出登录（前端清除 token） |

示例：

```bash
curl -X POST http://localhost:3000/api/auth/login ^
  -H "Content-Type: application/json" ^
  -d "{\"username\":\"admin\",\"password\":\"admin123\"}"
```

## 3.2 商品与分类（顾客端）

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/categories` | 分类列表（含每个分类在售商品数） |
| GET | `/flowers` | 商品列表，支持 `keyword / categoryId / minPrice / maxPrice / sort / page / pageSize / recommended` |
| GET | `/flowers/recommend` | 首页推荐商品，`limit` 默认 8 |
| GET | `/flowers/:id` | 商品详情（含评分、销量、收藏状态） |
| GET | `/flowers/:id/reviews` | 商品评价列表（分页） |

`sort` 取值：`default`（综合）、`sales`、`price_asc`、`price_desc`、`new`、`rating`。

```bash
curl "http://localhost:3000/api/flowers?keyword=%E7%8E%AB%E7%91%B0&sort=sales&page=1&pageSize=8"
```

## 3.7 错误码约定

| code | 含义 | 典型场景 |
| --- | --- | --- |
| 0 | 成功 | — |
| 400 | 参数/业务校验失败 | 库存不足、状态不允许、账号已存在 |
| 401 | 未登录或 token 失效 | 未携带 token、token 过期 |
| 403 | 无权限 | 普通用户访问 `/admin/*`、账号被禁用 |
| 404 | 资源不存在 | 商品/订单不存在 |
| 500 | 服务器内部错误 | 异常 SQL、未知错误 |

# 🌸 鲜花订购与管理系统

> 毕业设计项目 · 广东交通职业技术学院 软件技术专业
> 一套**前后端分离**的网上花店全流程系统：顾客端选购下单 + 管理端商品/订单/用户/数据管理

---

## 一、项目简介

系统模拟网上花店的业务流程，实现"鲜花浏览 → 加入购物车 → 下单支付 → 商家发货 → 确认收货 → 评价"的完整闭环，并为管理员提供商品管理、库存管理、订单处理、用户管理与经营数据看板。

- **顾客端**：注册登录、分类浏览、关键词搜索、商品详情、收藏、购物车、满减结算、模拟支付、订单跟踪、评价晒单、收货地址与个人资料管理
- **管理端**：数据概览（4 项核心指标 + 4 类图表）、商品 CRUD / 上下架 / 库存调整、分类管理、订单发货与状态流转、用户启用禁用与密码重置、评价审核与商家回复、操作日志审计

## 二、技术选型

| 层次 | 技术 | 说明 |
| --- | --- | --- |
| 前端 | HTML5 + CSS3 + 原生 JavaScript（ES6+） | 零构建、零框架依赖，双击即可运行，便于答辩演示 |
| 图表 | 自研 SVG 图表组件（`assets/js/chart.js`） | 折线图 / 柱状图 / 环形图，不依赖 ECharts CDN，断网也能演示 |
| 后端 | Node.js + Express 4 | 轻量、易部署、生态成熟 |
| 数据库 | SQLite（优先使用 Node 内置 `node:sqlite`，零安装） | 单文件数据库，免安装免配置 |
| 鉴权 | 自研 JWT（HS256，Node 内置 `crypto`） | 无第三方依赖，含角色权限区分 |
| 密码 | `crypto.scryptSync` 加盐哈希 | 不以明文保存密码 |

> 为什么是"零依赖"：后端除 `express` 外不依赖任何 npm 包，前端完全不依赖外网 CDN，
> **断网环境下也能完整演示**，避免答辩现场因网络/CDN 失效导致页面空白。

## 四、快速开始

### 方式一：一键启动（推荐，Windows）

双击根目录的 **`启动项目.bat`**，脚本会自动：

1. 检测 Node.js 环境
2. 安装后端依赖（首次运行）
3. 初始化数据库与演示数据
4. 启动服务并自动打开浏览器

### 方式二：命令行

```bash
cd E:\Flower\server
npm install        # 安装依赖（仅 express）
npm run reset      # 初始化数据库与演示数据（首次必须执行）
npm start          # 启动服务
```

### 方式三：前后端分开跑（前端 Node + 后端 IDEA，日常开发与答辩推荐）

后端交给 IDEA 管理，前端用独立的 Node 静态服务启动，两边互不干扰，改页面时不用重启后端。

**① 后端（IDEA）**：用 IDEA 打开 `E:\Flower\server`，右上角运行配置选择 **`1 后端服务 3000`** → Run。

**② 前端（Node）**：

```bash
cd E:\Flower\web
npm install        # 无第三方依赖，秒完成；也可完全跳过
npm start          # 等价于 node server.js
```

或双击根目录的 **`启动前端.bat`**。

**启动成功后访问：**

| 入口 | 地址 | 说明 |
| --- | --- | --- |
| 顾客端首页 | http://localhost:5173/ | 静态页面由 Node 提供 |
| 管理后台 | http://localhost:5173/admin/index.html | 同上 |
| 接口转发 | `/api/*` → `http://localhost:3000/api/*` | 由 `web/server.js` 自动代理 |

> `web/server.js` 用 Node 内置模块实现，**零第三方依赖**，并且把 `/api` 请求转发到后端，
> 所以前端 `api.js` 里的 `BASE = '/api'` 一行都不用改，也不存在跨域问题。

详细配置（IDEA 节点解释器、运行参数、环境变量、常见问题）见
**`docs/08-前后端分工运行说明.md`**。

## 五、功能模块

### 顾客端

1. 注册登录：账号格式校验、密码强度校验、重复注册拦截、登录失败提示、JWT 鉴权
2. 商品浏览：分类筛选、价格区间、关键词搜索、6 种排序、分页
3. 商品详情：花语 / 花材 / 包装、评分与销量、库存展示、收藏
4. 购物车：增删改数量、勾选结算、库存校验、满减优惠自动计算
5. 下单结算：收货地址选择/新增、订单备注、事务内扣减库存
6. 模拟支付：3 种支付方式、30 分钟倒计时
7. 订单中心：状态 Tab 筛选、订单搜索、支付 / 取消 / 确认收货 / 删除、物流时间轴
8. 评价晒单：1-5 星 + 文字评价，管理端可回复
9. 个人中心：资料修改、收货地址管理、我的收藏、修改密码

### 管理端

1. 数据概览：销售额 / 订单数 / 待发货 / 用户数 4 项指标，近 7 日趋势、分类占比、热销 TOP5、状态分布、最新订单、操作日志
2. 商品管理：新增 / 编辑 / 删除 / 上下架 / 推荐位 / 库存快捷调整 / 图片选择器
3. 分类管理：新增 / 编辑 / 删除（有商品时禁止删除）
4. 订单管理：多条件筛选、详情、发货、状态推进、取消（库存回滚）
5. 用户管理：查询、新增、禁用/启用、重置密码
6. 评价管理：查询、隐藏/展示、商家回复、删除

## 六、订单状态机

```
待付款 pending ──支付──> 待发货 paid ──发货──> 待收货 shipped ──确认收货──> 已完成 completed
     │                      │                      │
     └──────────────  取消 canceled（库存自动回滚） ──────────────┘
```

- 非法状态流转会被后端拦截并返回明确提示（如"订单当前状态为待发货，无法执行该操作"）
- 取消订单在数据库事务中回滚库存与销量，避免超卖

## 八、常见问题

**Q1：提示"无法初始化 SQLite"？**
请使用 Node.js 18 及以上版本；若使用 Node 16 及以下，请在 `server` 目录执行 `npm install better-sqlite3` 后重试。

**Q2：端口被占用？**
在 `server` 目录创建 `.env` 文件，写入 `PORT=4000` 后重启；或修改 `src/config.js`。

**Q3：数据库想恢复初始状态？**
执行 `npm run reset`。服务运行中也能执行——脚本检测到数据库文件被占用时会自动改用「清空数据表」方式重建，数据立即生效，无需先停服务。

**Q4：图片不显示？**
商品图片为本地 SVG，位于 `web/assets/images/flowers/`，无需联网。
